# faruk.page

Personal site of Faruk Keskin — demographer and researcher at Hacettepe University
Institute of Population Studies.

Live at [faruk.page](https://faruk.page).

Plain HTML/CSS/JS — no build step, no dependencies, no framework. Bilingual (EN/TR)
via a language toggle that shows/hides `data-en`/`data-tr` elements with CSS.

## Structure

```
index.html       Home
cv.html          Full CV
projects.html    Selected projects
courses.html     Courses taught
blog/            Blog — post index + individual posts
feed.xml         Atom feed for the blog
veridem/         Feed of instant Türkiye demographic data-change notices
css/style.css    Stylesheet
js/main.js       Language toggle + obfuscated email link
img/             Favicon
```
